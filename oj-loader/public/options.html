OJ Loader

Settings

Companion to OJ Runner in Visual Studio Code (official Microsoft build). The toolbar button POSTs extracted JSON to OJ Runner on your machine. Nothing is copied to the clipboard. Keep localhost HTTP enabled so Chrome does not need a vscode:// prompt for normal imports.

Local HTTP

Recommended

Must match OJ Runner settings ojRunner.localImportPort (default 17337) and path /import. OJ Runner must be running in VS Code with the local import server enabled. If the POST fails, you get a red badge; enable the fallback below to open the editor.

Fallback

VS Code default above. This does not import samples - use it to jump to OJ Runner when localhost is down. Manual JSON paste remains in OJ Runner's Samples view.

Submit bridge

In VS Code run OJ Runner: Copy Submit Bridge URL and paste the result here. The token in it is what keeps other pages and local programs off the socket, so treat the URL as a password and do not share it. Submissions are then sent from the judge tab using your existing login - OJ Loader never sees your judge password.
